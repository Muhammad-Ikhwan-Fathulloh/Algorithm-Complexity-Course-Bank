Divide and Conquer II

Closest Pair, Karatsuba, Strassen, FFT - empat contoh Divide and Conquer yang lebih cepat daripada cara naif. Kuncinya: mengurangi jumlah submasalah rekursif (Karatsuba, Strassen) atau menggabungkan hasil bagian dengan biaya kecil (Closest Pair, FFT).

KERANGKA TEORI · 5W1H

Mengapa dan untuk apa D&C lanjutan ini?

What - Apa?

Empat algoritma D&C canggih: Closest Pair (geometri), Karatsuba (aritmatika besar), Strassen (aljabar linier), FFT (pemrosesan sinyal). Masing-masing memotong jumlah submasalah rekursif dari yang "wajar" ke lebih sedikit.

Why - Mengapa?

Karena brute force untuk masalah ini O(n²) atau O(n³). Satu pengurangan submasalah rekursif mengubah eksponen waktu secara dramatis - dari n² ke n^1.585 (Karatsuba) atau n³ ke n^2.807 (Strassen).

Who - Siapa?

Developer kriptografi (Karatsuba untuk RSA besar), engineer ML (Strassen/FFT untuk convolution jaringan saraf), pemrogram kompetitif (Closest Pair di computational geometry), dan peneliti AI (AlphaTensor mencari versi yang lebih baik).

When - Kapan?

Karatsuba: bilangan >1000 digit. Strassen: matriks >~512×512. FFT: polinomial berderajat >1000 atau konvolusi sinyal panjang. Closest Pair: n titik >10.000 di mana brute force O(n²) terlalu lambat.

Where - Di mana?

Karatsuba di library kriptografi (Python int otomatis). FFT di NumPy, SciPy, pemrosesan audio/gambar. Strassen di library BLAS eksperimental. Closest Pair di computational geometry, GIS, computer graphics.

How - Bagaimana?

Kunci setiap algoritma: temukan identitas aljabar yang memungkinkan menghitung n perkalian dengan n-1 perkalian rekursif - lalu buktikan lewat Master Theorem bahwa pengurangan satu submasalah itu cukup untuk turunkan eksponen.

BAGIAN 1 · CLOSEST PAIR OF POINTS

Closest Pair - Θ(n log n) vs Θ(n²) brute force

Diberikan n titik di bidang 2D, cari dua titik terdekat. Brute force cek semua pasangan: O(n²). D&C bisa Θ(n log n).

Algoritma D&C (versi Θ(n log n)):
1. Urutkan titik berdasarkan koordinat-x
2. Bagi menjadi kiri dan kanan di garis tengah
3. Rekursif: δ_kiri = closest_pair(kiri), δ_kanan = closest_pair(kanan)
4. δ = min(δ_kiri, δ_kanan)
5. Combine: cari pasangan yang melintasi garis tengah dalam strip ±δ
6. Kunci: tiap titik di strip hanya perlu cek ≤ 7 tetangga terdekat!
Rekurens: T(n) = 2T(n/2) + O(n). Step combine O(n) jika strip sudah terurut menurut y (tiap titik cek ≤ 7 tetangga) → Master Theorem kasus 2 → Θ(n log n). Versi sederhana yang mengurutkan ulang strip di setiap level hanya O(n log² n) - itulah yang ada di notebook.
Kenapa maks 7 tetangga? Ambil persegi panjang δ × 2δ di sekitar garis tengah (δ di kiri, δ di kanan). Bagi jadi 8 kotak δ/2 × δ/2. Setiap kotak paling banyak 1 titik, karena dua titik di dalam satu kotak berjarak ≤ δ/√2 < δ, dan δ adalah jarak minimum yang sudah diketahui. Jadi ada paling banyak 8 titik, sehingga tiap titik cukup dibandingkan dengan 7 tetangga berikutnya.

BAGIAN 2 · KARATSUBA

Karatsuba - Θ(n^1.585): kurangi 4 perkalian jadi 3

Kalikan dua bilangan n-digit. Naif membutuhkan 4 perkalian setengah ukuran. Karatsuba (1960) menemukan: cukup 3 perkalian dengan menambah beberapa penjumlahan.

Identitas Karatsuba:
x = a·10^(n/2) + b, y = c·10^(n/2) + d
Naif: ac, ad, bc, bd → 4 perkalian
Karatsuba: hitung ac, bd, (a+b)(c+d)
Lalu: ad + bc = (a+b)(c+d) − ac − bd
→ Hanya 3 perkalian rekursif! 
def karatsuba(x, y):
    if x < 10 or y < 10: return x * y
    n = max(len(str(x)), len(str(y)))
    m = n // 2
    a, b = x // 10**m, x % 10**m
    c, d = y // 10**m, y % 10**m
    ac = karatsuba(a, c)
    bd = karatsuba(b, d)
    mid = karatsuba(a+b, c+d) - ac - bd
    return ac*(10**(2*m)) + mid*(10**m) + bd

BAGIAN 3 · STRASSEN + ALPHATENSOR

Strassen Θ(n^2.807) - dan AlphaTensor melampaui Strassen

Kalikan dua matriks n×n. Naif O(n³) (8 perkalian submatriks). Strassen (1969): hanya 7 perkalian, Θ(n^2.807). Perbedaan kecil di level submasalah = perbedaan besar secara asimtotik.

Ide Strassen: partisi A, B menjadi blok 2×2. Naif: 8 perkalian. Strassen: temukan 7 perkalian M1..M7 dengan 18 penjumlahan ekstra - tapi waktu penjumlahan O(n²) tidak mendominasi.

T(n) = 7T(n/2) + n² → log₂7 ≈ 2.807 > 2 → Kasus 1 → Θ(n^2.807)

[Modern] AlphaTensor - DeepMind 2022

RL menemukan cara kalikan matriks 4×4 dengan 47 perkalian (vs 49 untuk Strassen dua tingkat), pada aritmetika modulo 2. Rekurens: T(n) = 47T(n/4) + n² → log₄47 ≈ 2.777 → Θ(n^2.777). Pertama kali Strassen dilampaui dalam 53 tahun. Dipublikasikan di Nature, Oktober 2022.

Praktis: Strassen jarang dipakai di library produksi (BLAS, cuBLAS) karena konstanta besar dan cache-unfriendly. Mulai efektif di n ≳ 512. AlphaTensor masih di tahap riset.
BAGIAN 4 · FFT

FFT - Θ(n log n): perkalian polinomial dan konvolusi

Kalikan dua polinomial derajat n. Naif: O(n²). FFT: O(n log n). Salah satu algoritma paling berpengaruh dalam sejarah komputasi.

Ide FFT (Cooley-Tukey 1965):
1. Evaluate: representasikan polinomial sebagai nilai di n titik khusus (akar ke-n dari 1)
2. Pointwise multiply: kalikan nilai per titik → O(n)
3. Interpolate: kembalikan ke koefisien via inverse FFT

Rekurens: T(n) = 2T(n/2) + O(n) - identik Merge Sort! → Θ(n log n)
FFT dipakai di: MP3/JPEG compression, deep learning convolution (via im2col + FFT), radar/sonar signal processing, algoritma perkalian integer besar (n-digit × n-digit dalam Θ(n log n log log n)).

Soal D&C II

2

3

4

KUNCI JAWABAN

Kunci D&C II

1

δ = jarak terkecil yang ditemukan di sisi kiri atau kanan, jadi dua titik mana pun di sisi yang sama berjarak ≥ δ. Ambil persegi panjang δ × 2δ di sekitar garis tengah dan bagi menjadi 8 kotak δ/2 × δ/2. Diagonal tiap kotak = δ/√2 < δ, jadi tiap kotak memuat paling banyak 1 titik. Maka ada paling banyak 8 titik di dalam area itu, dan titik ke-8 cukup dibandingkan dengan 7 titik lain.

2

T(n) = 3T(n/2) + n. a=3, b=2, d=1. log₂3 ≈ 1.585 > 1 = d → Kasus 1 Master Theorem → Θ(n^log₂3) = Θ(n^1.585). Vs naif T(n)=4T(n/2)+n → log₂4=2 → Θ(n²). Selisih satu submasalah → eksponen turun dari 2 ke 1.585.

3

T(n)=7T(n/2)+n². log₂7 ≈ 2.807 > 2 = d → Θ(n^2.807) vs naif Θ(n³). Jika ada cara dengan 6 perkalian untuk blok 2×2, eksponennya log₂6 ≈ 2.585 → Θ(n^2.585). Namun 7 untuk blok 2×2 sudah sangat sulit diperbaiki; kemajuan nyata datang dari blok yang lebih besar (seperti AlphaTensor). Sampai tulisan ini, batas terbaik yang diketahui untuk perkalian matriks umum adalah ~n^2.372.

4

log₄47 = ln(47)/ln(4) ≈ 3.850/1.386 ≈ 2.777. Untuk n=4096=4^6: Strassen ≈ 4096^2.807 ≈ 1,4×10¹⁰ dan AlphaTensor ≈ 4096^2.777 ≈ 1,1×10¹⁰ → sekitar 22% lebih sedikit operasi (rasio 4096^0,03 ≈ 1,28). Selisih eksponennya kecil, tapi dampaknya terasa pada n besar.

5

Perlu dicatat: operator * bawaan Python sudah memakai Karatsuba untuk bilangan besar (CPython mulai dari sekitar 70 limb 30-bit, kira-kira 630 digit desimal). Karena itu Karatsuba manual biasanya tidak lebih cepat dari operator bawaan - overhead rekursi Python lebih besar daripada implementasi C. Yang terlihat jelas adalah perbandingan dengan perkalian sekolah dua loop, dan titik potongnya bergantung mesin: ukur sendiri di Colab.
