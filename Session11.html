PETA LANGKAH · KENAPA PENTING

Peta langkah: DP pada sekuens dan graf

1. LCS dan Edit distance
Definisikan dp[i][j] sebagai nilai untuk prefiks ke-i dan ke-j. Transisinya: cocok, sisip, hapus, atau ganti.
2. Rekonstruksi jawaban
Simpan pilihan di setiap sel, lalu telusuri tabel dari pojok kanan bawah (backtrace) untuk mendapatkan sekuens.
3. Relaksasi jalur
Bellman-Ford mengulang relaksasi semua sisi V−1 kali (O(VE)). Floyd-Warshall menghitung semua pasang sekaligus (O(V³)).
4. Viterbi
Pada HMM, simpan probabilitas terbaik untuk tiap state di tiap waktu, lalu telusuri jalur terbaiknya.
5. Cek kompleksitas
LCS dan Edit distance O(mn). Viterbi O(T·S²) untuk T langkah dan S state.
Kenapa penting: Pola DP pada sekuens dipakai di diff file, spell checker, pengenalan suara, dan NLP. Dengan menguasai tabel DP, Anda bisa membaca banyak algoritma sekaligus.
Tabel DP sering bisa dikecilkan memorinya: untuk LCS, cukup menyimpan dua baris saja jika jawaban panjangnya tidak perlu direkonstruksi.

Bagian A · Teori · Rumus 1/4 - cara membaca

Longest Common Subsequence

L[i][j] = { L[i−1][j−1] + 1  jika xi = yj;   maks(L[i−1][j], L[i][j−1])  jika tidak }

Cara membaca rumus ini

“L i j sama dengan L i kurang satu, j kurang satu, ditambah satu jika karakter x i sama dengan y j. Jika tidak sama, L i j adalah maksimum antara L i kurang satu j dan L i, j kurang satu.”
1

L[i][j]

panjang LCS dari i karakter pertama x dan j karakter pertama y.

2

Cocok (diagonal)

karakter sama → perpanjang LCS dari kedua prefiks yang lebih pendek.

3

Tidak cocok

buang satu karakter dari x ATAU dari y, ambil yang hasilnya lebih panjang.

Arti tiap simbol

x, ydua barisan (string) yang dibandingkan
i, jpanjang prefiks x dan y
L[0][*] = L[*][0] = 0basis: prefiks kosong
Θ(mn)ukuran tabel m × n
Intuisinya: Subsequence boleh melompat (tidak harus berurutan langsung). Tabel menyimpan jawaban untuk semua pasangan prefiks, sehingga tiap sel cukup melihat tiga tetangga.
Bagian A · Teori · Rumus 2/4 - cara membaca

Levenshtein (edit distance)

D[i][j] = min( D[i−1][j] + 1,  D[i][j−1] + 1,  D[i−1][j−1] + [xi ≠ yj] )

Cara membaca rumus ini

“D i j sama dengan minimum dari tiga hal: D i kurang satu j tambah satu untuk menghapus, D i j kurang satu tambah satu untuk menyisipkan, dan D i kurang satu j kurang satu ditambah satu jika x i berbeda dengan y j, untuk mengganti.”
1

Atas + 1 = hapus

buang xᵢ.

2

Kiri + 1 = sisip

tambahkan yⱼ.

3

Diagonal + [xᵢ ≠ yⱼ]

ganti (biaya 1) atau biarkan jika sama (biaya 0).

4

[kondisi]

notasi Iverson: bernilai 1 bila benar, 0 bila salah.

Arti tiap simbol

D[i][j]jumlah edit minimum mengubah x[1..i] menjadi y[1..j]
D[i][0] = ihapus semua
D[0][j] = jsisip semua
[x ≠ y]biaya ganti: 0 atau 1
Intuisinya: Setiap edit terakhir pasti salah satu dari tiga jenis. Coba ketiganya, ambil yang termurah - struktur yang sama dengan LCS, hanya min menggantikan maks.
Bagian A · Teori · Rumus 3/4 - cara membaca

Relaksasi Floyd-Warshall (dan Bellman-Ford)

d[i][j] ← min( d[i][j],  d[i][k] + d[k][j] )  untuk k = 1..V  ⇒  Θ(V³);   Bellman-Ford: V−1 putaran × E = O(VE)

Cara membaca rumus ini

“d i j diperbarui menjadi minimum antara d i j sekarang dan d i k ditambah d k j, untuk setiap simpul perantara k dari satu sampai V. Totalnya Theta V pangkat tiga. Bellman-Ford melakukan V kurang satu putaran atas semua E sisi, O V E.”
1

k = simpul perantara

setelah putaran k, d[i][j] = jarak terpendek yang hanya boleh transit di simpul 1..k.

2

d[i][k] + d[k][j]

jalur i → k → j.

3

Tiga loop bersarang

k (luar), i, j → V³.

4

Bellman-Ford

relaksasi semua sisi V−1 kali; putaran ke-V yang masih berubah = ada siklus negatif.

Arti tiap simbol

d[i][j]jarak terpendek i → j sejauh ini
ksimpul perantara yang diizinkan
V, Ebanyaknya simpul dan sisi
siklus negatifsiklus dengan total bobot < 0
Intuisinya: Floyd-Warshall menjawab semua pasangan sekaligus dengan kode tiga baris. Bellman-Ford lebih lambat dari Dijkstra tetapi tahan bobot negatif dan bisa mendeteksi siklus negatif.
Bagian A · Teori · Rumus 4/4 - cara membaca

Rekurens Viterbi

Vt(s) = makss′ [ Vt−1(s′) · as′s ] · bs(ot);   O(T·S²)

Cara membaca rumus ini

“V t dari s sama dengan maksimum atas semua state sebelumnya s aksen, dari V t kurang satu dari s aksen dikali peluang transisi a dari s aksen ke s, lalu dikali peluang emisi b s dari observasi o t. Biayanya O T kali S kuadrat.”
1

Vₜ(s)

peluang jalur state TERBAIK yang berakhir di state s pada waktu t.

2

a_{s′s}

peluang pindah dari state s′ ke s (transisi).

3

b_s(oₜ)

peluang state s menghasilkan observasi oₜ (emisi).

4

maks + simpan argmax

di akhir, telusuri balik pointer untuk mendapatkan urutan state.

Arti tiap simbol

tposisi waktu/kata ke-t (1..T)
s, s′state sekarang dan sebelumnya (S buah)
oₜobservasi ke-t (kata, sinyal)
T·S²T kolom × S state × S kandidat sebelumnya
Intuisinya: Mencoba semua urutan state butuh Sᵀ. Viterbi memakai fakta bahwa jalur terbaik ke (t, s) pasti melewati jalur terbaik ke salah satu (t−1, s′) - optimal substructure.

BAGIAN 1 · LCS

Longest Common Subsequence - O(mn)

LCS("ABCBDAB", "BDCAB") = 4 ("BCAB" atau "BDAB"). Beda dengan substring: subsequence tidak harus berurutan bersebelahan.

Rekurens:
Jika X[i]=Y[j]: lcs[i][j] = lcs[i-1][j-1] + 1
Selain itu: lcs[i][j] = max(lcs[i-1][j], lcs[i][j-1]) 
def lcs(X, Y):
    m, n = len(X), len(Y)
    dp = [[0]*(n+1) for _ in range(m+1)]
    for i in range(1, m+1):
        for j in range(1, n+1):
            if X[i-1] == Y[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]  # O(mn) waktu, O(mn) ruang
LCS adalah fondasi dari git diff, diff Unix, dan tools perbandingan teks. Panjang LCS bisa jadi ukuran kemiripan dua string.
Coba sendiri · Edit Distance (terkait LCS)
Masukkan dua kata lalu klik Hitung.
Cara membaca rumus:
• Jika X[i] = Y[j]: lcs[i][j] = lcs[i−1][j−1] + 1, yaitu huruf yang sama menambah panjang LCS.
• Jika tidak sama: lcs[i][j] = max(lcs[i−1][j], lcs[i][j−1]), ambil yang terpanjang dari dua kemungkinan.
• Tabel (m+1) × (n+1) diisi dalam O(mn).
BAGIAN 2 · EDIT DISTANCE

Levenshtein Distance - O(mn)

Jumlah minimum operasi (insert, delete, replace) untuk mengubah string A ke string B. Digunakan di spell checker, DNA alignment, autocorrect.

Rekurens:
Jika A[i]=B[j]: dp[i][j] = dp[i-1][j-1] (gratis)
Selain itu: dp[i][j] = 1 + min(
  dp[i-1][j],    ← delete dari A
  dp[i][j-1],    ← insert ke A
  dp[i-1][j-1])  ← replace
Analogi - penyunting naskah. Berapa kali harus coret, tambah, atau ganti kata untuk ubah draft A jadi draft B? Edit Distance itu versi formalnya - dan tabelnya mirip persis dengan meja kerja penyunting yang memeriksa tiap bagian secara sistematis.
OperasiBiayaAplikasi
Insert1Autocorrect
Delete1Spell checker
Replace1DNA alignment
Edit distance dengan bobot berbeda per operasi dinamakan Weighted Edit Distance. Di NLP, misalnya typo "teh" → "the" (transpose) dimodelkan berbeda. Algoritma Damerau–Levenshtein menambahkan operasi transpose.

Hubungan LCS ↔ Edit Distance:

edit_dist(A,B) = m + n − 2·LCS(A,B) - untuk operasi insert/delete saja. Jadi kedua masalah ini terhubung erat.

Cara membaca rumus:
• Jika A[i] = B[j]: dp[i][j] = dp[i−1][j−1] (tidak ada biaya).
• Jika tidak: dp[i][j] = 1 + min(dp[i−1][j], dp[i][j−1], dp[i−1][j−1]).
• Tiga pilihan: hapus dari A, sisip ke A, atau ganti karakter. Masing-masing biaya 1.
BAGIAN 3 · DP PADA GRAF

Bellman-Ford O(VE) dan Floyd-Warshall O(V³)

Bellman-Ford - Single source, boleh ada edge negatif

def bellman_ford(graph, src):
    dist = {v: float('inf') for v in graph}
    dist[src] = 0
    for _ in range(len(graph) - 1):  # V-1 iterasi
        for u, v, w in graph.edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
    # cek negative cycle
    for u, v, w in graph.edges:
        if dist[u] + w < dist[v]:
            raise ValueError("Negative cycle!")
    return dist  # O(VE)

Floyd-Warshall - All-pairs shortest path

def floyd_warshall(W):  # W = matriks bobot
    n = len(W)
    dist = [row[:] for row in W]
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    return dist  # O(V³) waktu, O(V²) ruang
AlgoritmaWaktuNegatif?Semua pasang?
DijkstraO(E log V)✗✗
Bellman-FordO(VE)✓✗
Floyd-WarshallO(V³)✓✓
Cara membaca rumus:
• Bellman-Ford: O(VE), V = jumlah simpul, E = jumlah sisi.
• Floyd-Warshall: O(V³), menghitung jarak semua pasangan simpul sekaligus.
• Dijkstra: O(E log V), tetapi tidak bisa bobot negatif.

Bagian B · Teknikal · Rumus 1/4 - kode Python

Dari hitungan ke kode: Longest Common Subsequence

Kode Python

def lcs(x, y):
    m, n = len(x), len(y)
    L = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            L[i][j] = (L[i-1][j-1] + 1 if x[i-1] == y[j-1]
                       else max(L[i-1][j], L[i][j-1]))
    return L[m][n]

print(lcs("ABCB", "BDCAB"))   # 3

Bagian B · Teknikal · Rumus 2/4 - kode Python

Dari hitungan ke kode: Levenshtein (edit distance)

Kode Python

def edit_distance(x, y):
    prev = list(range(len(y) + 1))
    for i, a in enumerate(x, 1):
        cur = [i]
        for j, b in enumerate(y, 1):
            cur.append(min(prev[j] + 1, cur[j-1] + 1, prev[j-1] + (a != b)))
        prev = cur
    return prev[-1]

print(edit_distance("kitten", "sitting"))   # 3

def floyd_warshall(d):            # d: matriks V x V, inf jika tak ada sisi
    V = len(d)
    for k in range(V):
        for i in range(V):
            for j in range(V):
                if d[i][k] + d[k][j] < d[i][j]:
                    d[i][j] = d[i][k] + d[k][j]
    return d

INF = float("inf")
print(floyd_warshall([[0,4,9],[4,0,1],[9,1,0]])[0][2])   # 5

Kode Python

def viterbi(obs, states, start, trans, emit):
    V = [{s: start[s] * emit[s][obs[0]] for s in states}]
    back = []
    for o in obs[1:]:
        prev = V[-1]; row, ptr = {}, {}
        for s in states:
            best = max(states, key=lambda p: prev[p] * trans[p][s])
            row[s] = prev[best] * trans[best][s] * emit[s][o]; ptr[s] = best
        V.append(row); back.append(ptr)
    s = max(V[-1], key=V[-1].get); path = [s]
    for ptr in reversed(back): s = ptr[s]; path.append(s)
    return path[::-1]

BAGIAN 4 · [MODERN] DP PADA URUTAN

Viterbi - DP paling berpengaruh di NLP

Viterbi algorithm mencari urutan state paling mungkin dalam Hidden Markov Model (HMM). Digunakan di speech recognition, POS tagging, dan bioinformatics.

HMM: state tersembunyi (misalnya POS tag), observasi (kata), probabilitas transisi dan emisi.

Masalah decoding: diberikan urutan kata, cari urutan POS tag yang paling mungkin.

Naive: O(K^T) - K state, T panjang urutan
Viterbi DP: O(K²·T) - karena optimal substructure
Kalau ada T=100 kata dan K=10 POS tag: naive = 10^100 kombinasi. Viterbi = 100×100 = 10.000 langkah. Ini perbedaan yang tidak masuk akal vs sangat efisien - dan DP yang memungkinkan ini.
def viterbi(obs, states, start_p, trans_p, emit_p):
    V = [{}]
    for st in states:
        V[0][st] = start_p[st] * emit_p[st][obs[0]]
    for t in range(1, len(obs)):
        V.append({})
        for st in states:
            V[t][st] = max(
                V[t-1][prev] * trans_p[prev][st] * emit_p[st][obs[t]]
                for prev in states)
    # O(K² × T) vs naive O(K^T)
    return max(V[-1], key=V[-1].get)
Analogi - DP tangga lagi. Tiap langkah, simpan probabilitas tertinggi untuk sampai ke state ini. Langkah berikutnya tinggal ambil simpanan dari langkah sebelumnya - tidak perlu menghitung semua jalur dari awal.
Cara membaca rumus:
• Viterbi menyimpan δₜ(j): probabilitas terbaik sampai langkah t dan berada di state j.
• Rekurens: δₜ(j) = maks_i [δₜ₋₁(i) · a_ij] · b_j(oₜ), dengan a = transisi dan b = emisi.
• Telusuri balik dari δ_T terbesar untuk mendapatkan urutan state terbaik.
