BAGIAN 1 · PRINSIP BACKTRACKING

Backtracking = DFS dengan pruning

Bangun solusi langkah demi langkah. Kalau langkah saat ini sudah melanggar constraint (tidak bisa menuju solusi valid), batalkan dan coba pilihan berikutnya.

def backtrack(state, candidates):
    if is_solution(state):
        solutions.append(state[:])
        return
    for choice in candidates:
        if is_valid(state, choice):   # ← pruning
            state.append(choice)
            backtrack(state, next_candidates(state))
            state.pop()               # ← undo
Analogi - isi TTS (teka-teki silang). Mulai dari kotak pertama, coba huruf A. Lanjut ke kotak berikutnya, coba A lagi. Kalau di suatu titik tidak ada kata yang cocok → hapus kotak terakhir, coba huruf B. Terus mundur sampai ketemu atau semua kemungkinan habis.

Kompleksitas backtracking:

Tanpa pruning: O(k^n) di mana k = pilihan per langkah, n = kedalaman. Dengan pruning yang efektif: bisa jauh lebih kecil - tapi sulit dianalisis secara eksak. Worst case tetap eksponensial.

MasalahTanpa pruning (ruang pencarian)Dengan pruning
N-Queens (n=8)8^8 ≈ 16,7 juta penempatan15.720 penempatan untuk mencari semua 92 solusi (cek kolom & diagonal)
Sudoku9^81 (sangat besar)Jauh lebih sedikit, bergantung pada puzzle (lihat notebook)
TSP (n=10)10!Jauh lebih sedikit
Pruning itu senjata utama backtracking. Semakin awal kita deteksi constraint violation, semakin banyak cabang yang bisa dipotong.
Cara membaca rumus:
• Tanpa pruning: O(kⁿ), dengan k = pilihan per langkah dan n = kedalaman.
• 8⁸ ≈ 16,7 juta: ruang pencarian 8-Queens jika setiap baris mencoba 8 kolom tanpa pemangkasan.
BAGIAN 2 · N-QUEENS

N-Queens - Tempatkan n ratu tanpa saling serang

Tempatkan n ratu di papan n×n sehingga tidak ada dua ratu yang serang (baris, kolom, diagonal).

def solve_nqueens(n):
    solutions = []
    def bt(row, cols, diag1, diag2):
        if row == n:
            solutions.append(cols[:])
            return
        for col in range(n):
            if col in set(cols): continue
            if (row-col) in diag1: continue
            if (row+col) in diag2: continue
            cols.append(col)
            bt(row+1, cols,
               diag1|{row-col}, diag2|{row+col})
            cols.pop()
    bt(0, [], set(), set())
    return solutions
Pruning tiga kondisi: kolom sudah terpakai, diagonal utama (/), diagonal sekunder (\). Ketiga cek ini O(1) pakai set → pruning sangat efektif.

BAGIAN 3 · CSP

Constraint Satisfaction Problem - formalisme yang kuat

CSP mendefinisikan masalah sebagai triplet (X, D, C): variabel, domain, constraint. Backtracking + inferensi constraint = cara standar menyelesaikan CSP.

KomponenContoh: pewarnaan peta
Variabel XProvinsi: A, B, C, D
Domain DWarna: {merah, hijau, biru}
Constraint CProvinsi tetangga ≠ warna sama
Penjadwalan kuliah = CSP: variabel = mata kuliah, domain = slot waktu, constraint = tidak boleh bentrok. Google OR-Tools CP-SAT solver menyelesaikan CSP skala besar dengan teknik ini.

Forward Checking

Setelah assign variabel X=v, hapus v dari domain semua variabel tetangga. Kalau domain tetangga kosong → backtrack segera. Mencegah konflik sebelum terjadi.

AC-3 Arc Consistency

Propagasi constraint lebih kuat: pastikan untuk setiap nilai di domain X, ada nilai di domain Y yang konsisten. O(ED³) di mana E = arc, D = ukuran domain. Jauh lebih agresif memangkas domain.

Heuristik pemilihan variabel & nilai

MRV (Minimum Remaining Values): pilih variabel dengan domain terkecil dulu - yang paling "terdesak". LCV (Least Constraining Value): pilih nilai yang paling sedikit membatasi variabel lain.

Cara membaca rumus:
• CSP = (X, D, C): X = variabel, D = domain nilai tiap variabel, C = constraint antar variabel.
• AC-3: O(ed³), dengan e = jumlah arc dan d = ukuran domain. Biaya propagasi konsistensi arc.

KUNCI JAWABAN

Kunci Backtracking dan CSP

1

Brute force menghasilkan dan menguji semua kandidat. Backtracking membangun kandidat secara inkremental dan membuang (prune) kandidat parsial yang sudah pasti gagal. Contoh: N-Queens 4×4, ratu pertama di baris 0 kolom 0 dan ratu kedua di baris 1 kolom 2. Pada baris 2, kolom 0 dan 2 sudah terpakai, sedangkan kolom 1 dan 3 diserang diagonal. Tidak ada kolom aman, jadi cabang ini dipangkas tanpa menjelajah lebih dalam.

2

Pencarian dengan urutan kolom 0 → 3 menemukan solusi pertama kolom [1, 3, 0, 2], yaitu ratu di (baris 0, kolom 1), (1, 3), (2, 0), (3, 2). Dengan pruning kolom dan diagonal, pencarian mencoba 26 penempatan sebelum sampai di sana (termasuk yang langsung ditolak). Ada dua solusi untuk 4×4: [1,3,0,2] dan [2,0,3,1]. Sebagai pembanding, brute force menguji semua 4⁴ = 256 kombinasi kolom per baris, sedangkan permutasi tanpa kolom ganda hanya 4! = 24.

3

Sudoku 4×4: X = 16 sel (yang kosong). D = {1,2,3,4} untuk tiap sel. C: setiap baris (4), kolom (4), kotak 2×2 (4) harus berisi nilai berbeda = 12 constraint alldiff. Total variabel ≤ 16, domain size = 4.

4

Forward Checking: propagasi 1 langkah ke depan, O(D) per assign. AC-3: propagasi penuh ke semua arc, O(ED³) sekali jalan. AC-3 lebih kuat (lebih banyak pruning), tapi lebih mahal per langkah. Trade-off: AC-3 sering worth it karena mengurangi backtrack jauh lebih banyak.

5

Secara umum, MRV + forward checking menghasilkan node jauh lebih sedikit daripada urutan sel tetap (kiri ke kanan, atas ke bawah), karena sel dengan domain terkecil dipilih dulu sehingga kegagalan terdeteksi lebih awal.
