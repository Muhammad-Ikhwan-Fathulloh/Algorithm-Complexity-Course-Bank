KOMPLEKSITAS ALGORITMA · PERTEMUAN 4

Divide and Conquer I

Pisahkan masalah jadi bagian lebih kecil, selesaikan masing-masing, gabungkan hasilnya. Strategi ini menghasilkan algoritma Θ(n log n) untuk masalah yang naifnya butuh Θ(n²).

Pertemuan ini: Merge Sort, Quick Sort, Binary Search, Quickselect - empat algoritma yang wajib dikenal setiap programmer.

Pindah: ← → · ← Daftar Materi
PETA LANGKAH · KENAPA PENTING

Peta langkah: Divide, Conquer, Combine

1. Divide
Bagi masalah menjadi bagian yang lebih kecil, biasanya dua bagian berukuran setengah.
2. Conquer
Selesaikan tiap bagian secara rekursif. Berhenti ketika masalahnya sudah sangat kecil (base case).
3. Combine
Gabungkan hasil bagian menjadi jawaban utuh. Biaya langkah ini menentukan total kompleksitas.
4. Tulis rekurensnya
T(n) = 2T(n/2) + biaya combine. Lalu selesaikan dengan Master Theorem.
5. Cek syarat
Binary search hanya benar jika data sudah terurut. Quick sort bergantung pada pemilihan pivot.
Kenapa penting: Pola tiga langkah ini dipakai di merge sort, quick sort, binary search, dan Quickselect. Setelah paham polanya, algoritma baru akan terasa mirip.
Quick sort Θ(n log n) hanya rata-rata. Pada input terburuk pivot yang buruk membuatnya O(n²), itulah alasan randomisasi dipakai.

WHAT - Apa itu Divide and Conquer?

Paradigma yang memecah masalah menjadi subsoal sejenis yang lebih kecil, menyelesaikannya secara rekursif, lalu menggabungkan hasilnya.

Divide

Belah input (misalnya di tengah array atau di sekitar pivot).

Conquer

Selesaikan tiap bagian secara rekursif; bagian kecil diselesaikan langsung.

Combine

Gabungkan jawaban bagian menjadi jawaban utuh (merge, atau tidak perlu sama sekali).

Contoh: Merge sort: belah dua → urutkan tiap separuh → gabungkan dua daftar terurut.

HOW - Bagaimana merancang algoritma D&C?

Ikuti empat pertanyaan:

1. Bagaimana membagi?

Di tengah (merge sort, binary search) atau di sekitar pivot (quicksort).

2. Apa kasus dasarnya?

Ukuran 0 atau 1 biasanya langsung selesai.

3. Bagaimana menggabung & berapa biayanya?

Tulis rekurensnya, lalu selesaikan dengan Master Theorem.

Contoh: Binary search: bagi di mid, buang separuh, tanpa combine → T(n) = T(n/2) + 1 = Θ(log n).
PRINSIP DIVIDE AND CONQUER

Tiga langkah: Divide → Conquer → Combine

1. Divide - Pecah masalah ukuran n menjadi a submasalah ukuran n/b.

2. Conquer - Selesaikan tiap submasalah secara rekursif. Kalau sudah cukup kecil, selesaikan langsung.

3. Combine - Gabungkan hasil submasalah menjadi solusi masalah asal.

Rekurensnya: T(n) = a·T(n/b) + f(n). Selesaikan dengan Master Theorem dari pertemuan kemarin.
Analogi - ngebagi tugas sensus. Sensus 1 juta penduduk: bagi ke 2 tim, masing-masing sensus 500 ribu. Tiap tim bagi lagi ke 2 tim kecil. Terus sampai tiap tim cuma sensus 1 orang (base case). Gabungkan hasilnya naik ke atas. Inilah Merge Sort.
AlgoritmaDivideConquerCombineΘ
Merge SortBelah 2RekursifMerge O(n)n log n
Quick SortPartitionRekursifGratis O(1)n log n*
Binary SearchCek tengah1 subsoalGratis O(1)log n
QuickselectPartition1 subsoalGratis O(1)n*

* = kasus rata-rata. Kasus terburuk Quick Sort dan Quickselect bisa O(n²) kalau pivot-nya selalu buruk.

Cara membaca rumus:
• T(n) = a·T(n/b) + f(n): a = jumlah submasalah, n/b = ukuran tiap submasalah, f(n) = biaya divide dan combine.
• Rumus ini dibaca langsung oleh Master Theorem untuk menentukan kompleksitasnya.

Banyaknya perbandingan merge sort

C(n) = 2·C(n/2) + (n − 1)  ⇒  C(n) ≤ n·⌈log2 n⌉

Cara membaca rumus ini

“C dari n sama dengan dua kali C dari n per dua ditambah n kurang satu, sehingga C dari n paling banyak n kali langit-langit log dua n.”
1

C(n)

banyaknya perbandingan untuk mengurutkan n elemen.

2

n − 1

merge dua daftar terurut berukuran total n butuh paling banyak n − 1 perbandingan.

3

⌈ ⌉ = ceiling

bulatkan ke atas: ⌈log₂ 1000⌉ = 10.

Arti tiap simbol

C(n)jumlah perbandingan (worst case)
2·C(n/2)mengurutkan dua separuh
n − 1biaya merge
⌈log₂ n⌉banyaknya level penggabungan
Intuisinya: Merge sort tidak peduli isi data: selalu dibelah tepat di tengah. Karena itu batasnya terjamin, tidak ada kasus buruk tersembunyi.
Bagian A · Teori · Rumus 2/4 - cara membaca

Quicksort: rata-rata vs terburuk

Rata-rata: 2n·ln n ≈ 1,39·n log2 n   |   Terburuk: T(n) = T(n−1) + n = Θ(n²)

Cara membaca rumus ini

“Rata-rata quicksort butuh dua n kali log natural n perbandingan, kira-kira satu koma tiga sembilan n log dua n. Kasus terburuknya T dari n sama dengan T dari n kurang satu tambah n, Theta n kuadrat.”
1

ln = log natural

ln n = log₂ n × 0,693 → 2 ln n ≈ 1,39 log₂ n.

2

Rata-rata

pivot acak rata-rata membagi data cukup seimbang.

3

Terburuk

pivot selalu elemen terkecil/terbesar → satu sisi kosong.

Arti tiap simbol

ln nlogaritma natural (basis e ≈ 2,718)
1,39konstanta: quicksort ~39% lebih banyak perbandingan dari batas ideal
T(n−1)sisi partisi yang hanya berkurang 1
Intuisinya: Walau perbandingannya sedikit lebih banyak dari merge sort, quicksort bekerja in-place dan ramah cache, jadi biasanya lebih cepat di praktik - asalkan pivotnya tidak sial.

BAGIAN 1 · MERGE SORT

Merge Sort - Θ(n log n) terjamin

def merge_sort(A):
    if len(A) <= 1: return A
    mid = len(A) // 2
    L = merge_sort(A[:mid])   # T(n/2)
    R = merge_sort(A[mid:])   # T(n/2)
    return merge(L, R)        # O(n)

def merge(L, R):              # O(n)
    out, i, j = [], 0, 0
    while i < len(L) and j < len(R):
        if L[i] <= R[j]:
            out.append(L[i]); i += 1
        else:
            out.append(R[j]); j += 1
    return out + L[i:] + R[j:]
# Rekurens: T(n)=2T(n/2)+n → Θ(n log n)
Merge Sort: selalu Θ(n log n) - kasus terbaik, rata-rata, terburuk sama semua. Tradeoff: butuh memori O(n) ekstra untuk merge. In-place merge sort ada tapi praktiknya lebih lambat.

BAGIAN 2 · QUICK SORT

Quick Sort - Θ(n log n) rata-rata, O(n²) terburuk

def quicksort(A, lo=0, hi=None):
    if hi is None: hi = len(A) - 1
    if lo >= hi: return
    p = partition(A, lo, hi)   # O(n)
    quicksort(A, lo, p - 1)
    quicksort(A, p + 1, hi)

def partition(A, lo, hi):
    pivot = A[hi]   # pivot = elemen terakhir
    i = lo - 1
    for j in range(lo, hi):
        if A[j] <= pivot:
            i += 1
            A[i], A[j] = A[j], A[i]
    A[i+1], A[hi] = A[hi], A[i+1]
    return i + 1
Kasus terburuk Quick Sort: array sudah terurut + pivot selalu elemen terakhir → partisi jadi 0 dan n-1 → T(n)=T(n-1)+n = O(n²). Solusinya: pivot acak (randomized quicksort).

• Kasus terburuk: T(n) = T(n−1) + n. Pivot selalu memisahkan 0 dan n−1 elemen.
• Menjumlahkan: n + (n−1) + … + 1 = n(n+1)/2 = Θ(n²).
BAGIAN 3 · BINARY SEARCH

Binary Search - Θ(log n) dengan syarat: data terurut

def binary_search(A, x):
    lo, hi = 0, len(A) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if A[mid] == x:
            return mid        # ketemu
        elif A[mid] < x:
            lo = mid + 1      # buang separuh kiri
        else:
            hi = mid - 1      # buang separuh kanan
    return -1                 # tidak ada
Analogi - buka kamus. Cari kata "kucing": buka tengah, "meja" - terlalu jauh ke belakang. Buka kiri, "hutan" - masih kurang. Terus biseksi. log₂(100.000) ≈ 17 langkah cukup untuk mencari di kamus 100 ribu kata.

Syarat penting: array harus sudah terurut. Kalau datanya dinamis (sering insert/delete), lebih baik pakai BST atau sorted container yang maintain urutan otomatis.

Rekurens: T(n) = T(n/2) + 1. Master Theorem kasus 2 (a=1, b=2, d=0, log_b a=0=d) → Θ(log n).

Cara membaca rumus:
• T(n) = T(n/2) + 1: tiap langkah membuang setengah data dan hanya melakukan 1 perbandingan.
• Master Theorem kasus 2 dengan a = 1, b = 2, d = 0 → Θ(log n).
• log₂100.000 ≈ 17, artinya cukup 17 langkah untuk 100 ribu data.
BAGIAN 4 · QUICKSELECT

Quickselect - Cari elemen ke-k tanpa sort penuh

Cari elemen ke-k terkecil (median, percentile). Tidak perlu sort semua elemen - hanya kejar satu partisi:

def quickselect(A, k, lo=0, hi=None):
    if hi is None: hi = len(A) - 1
    if lo == hi: return A[lo]
    p = partition(A, lo, hi)   # O(n)
    if p == k:   return A[p]
    elif p > k:  return quickselect(A, k, lo, p-1)
    else:        return quickselect(A, k, p+1, hi)
# Rekurens: T(n) = T(n/2) + n → Θ(n) rata-rata
Rata-rata pivot membelah array ke dua bagian sama besar, sehingga T(n) = T(n/2) + n → Θ(n). Ini lebih cepat dari sort + ambil elemen ke-k yang butuh Θ(n log n).
Analogi - cari nilai median ujian. Daripada urutkan semua nilai baru ambil yang tengah (O(n log n)), Quickselect langsung mengarah ke nilai ke-(n/2) dengan O(n) rata-rata. Bedanya makin terasa saat n besar.

Perbandingan:

CaraKompleksitas
Sort + ambil ke-kΘ(n log n)
Quickselect (avg)Θ(n)
Quickselect (worst)Θ(n²)
Median of mediansΘ(n) worst case
Python: heapq.nsmallest(k, A) untuk k kecil, atau gunakan introselect di library numpy. Quickselect murni cukup untuk n ≤ 10⁶.
Cara membaca rumus:
• Dengan pivot rata-rata: T(n) = T(n/2) + n. Biaya partisi n, lalu hanya satu sisi yang dilanjutkan.
• Deret n + n/2 + n/4 + … ≤ 2n, sehingga totalnya Θ(n).

Dari hitungan ke kode: Banyaknya perbandingan merge sort

Kode Python

def merge_sort(a):
    if len(a) <= 1: return a
    m = len(a) // 2
    L, R = merge_sort(a[:m]), merge_sort(a[m:])
    out, i, j = [], 0, 0
    while i < len(L) and j < len(R):
        if L[i] <= R[j]: out.append(L[i]); i += 1
        else:            out.append(R[j]); j += 1
    return out + L[i:] + R[j:]

Dari hitungan ke kode: Quicksort: rata-rata vs terburuk

Kode Python

import random
def quicksort(a):
    if len(a) <= 1: return a
    p = random.choice(a)          # pivot acak: hindari Theta(n^2)
    kiri  = [x for x in a if x < p]
    sama  = [x for x in a if x == p]
    kanan = [x for x in a if x > p]
    return quicksort(kiri) + sama + quicksort(kanan)

Kode Python

def binary_search(a, x):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = lo + (hi - lo) // 2     # aman dari overflow
        if a[mid] == x: return mid
        if a[mid] < x:  lo = mid + 1
        else:           hi = mid - 1
    return -1

Dari hitungan ke kode: Quickselect: mencari elemen ke-k

Kode Python

import random
def quickselect(a, k):              # elemen terkecil ke-k (0-based)
    p = random.choice(a)
    kiri  = [x for x in a if x < p]
    sama  = [x for x in a if x == p]
    if k < len(kiri):               return quickselect(kiri, k)
    if k < len(kiri) + len(sama):   return p
    kanan = [x for x in a if x > p]
    return quickselect(kanan, k - len(kiri) - len(sama))

KUNCI JAWABAN

Kunci Divide and Conquer I

1

T(n) = 2T(n/2) + n. a=2, b=2, d=1, log₂2=1=d → Kasus 2 → Θ(n log n). Biaya tiap level sama, ada log₂n level.

2

Degenerasi jika pivot selalu ekstrem (terkecil/terbesar), misalnya array sudah terurut naik + pivot=elemen terakhir: partisi selalu 0 dan n-1, T(n)=T(n-1)+n=O(n²). Solusi: random pivot atau median-of-three (pivot = median dari elemen pertama, tengah, terakhir).

3

Array biasa: insert O(n), search O(log n). BST seimbang (AVL/Red-Black) atau Python sortedcontainers.SortedList: insert O(log n), search O(log n). Untuk frekuensi insert tinggi, BST atau skip list jauh lebih baik.

4

Quicksort merekursif dua subarray (kiri dan kanan pivot) → T(n)=2T(n/2)+n → Θ(n log n). Quickselect hanya rekursif ke satu sisi (sisi yang mengandung elemen ke-k) → T(n)=T(n/2)+n → Kasus 3 Master Theorem → Θ(n).

5

Rasio waktu saat n×10 harus mendekati ×10·log(10n)/log(n) ≈ ×10–12 untuk Θ(n log n). Python sorted() (Timsort) lebih cepat dari Merge Sort murni karena optimasi C - tapi orde tetap sama, rasio mendekati 10×.
